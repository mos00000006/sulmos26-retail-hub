SULMOS26 POS WHITE ICON PATCH

This patch changes the installed POS app icon background from charcoal/black to white.

Files included:
- public-pos/manifest.webmanifest
- public-pos/assets/icon-192.png
- public-pos/assets/icon-512.png
- public-pos/assets/icon-maskable-512.png
- public-pos/assets/apple-touch-icon.png
- public-pos/assets/favicon-48.png

How to use:
1. Upload/replace these files in your GitHub repository.
2. Commit to main.
3. Run the POS deployment workflow again.
4. Uninstall the previously installed POS app from Windows/Chrome.
5. Reopen the POS site and install it again.

Note:
Chrome often caches old app icons, so reinstalling the app is usually required before the new white icon appears.
