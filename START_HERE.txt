SULMOS26 V25 — ONE-FILE GREEN HUB RECOVERY

PURPOSE
Restore original Green Hub interface from a syntax-checked full application file.
This replaces broken public/app.js which may contain merge conflict text.

DO NOT change:
- public/index.html
- src/index.ts
- Cloudflare D1/database/migrations
- public-pos (red POS)

INSTALL — Recommended: GitHub Upload files
1. Download and unzip this patch.
2. In GitHub go to repository / public folder.
3. Use Add file -> Upload files (drag the app.js inside the ZIP's public folder).
4. GitHub should show replacement of public/app.js. Commit to main.
5. In GitHub / public / app.js check its FIRST line starts with:
   const $=sel=>document.querySelector(sel);
6. Use GitHub file search for <<<<<<< and >>>>>>> — 0 results inside public/app.js.
7. Check GitHub Actions -> Sulmos26 Check is green.
8. Run Deploy Sulmos26 to Cloudflare (green Hub only).
9. Verify LIVE app.js returns JavaScript (starts with 'const'), not an HTML page.
   URL: https://sulmos26-retail-hub.moyanamoses006.workers.dev/app.js
10. Open Hub in Chrome and hard-refresh Ctrl+Shift+R, THEN installed app.

If /app.js in Chrome starts with <!doctype or <html, the deployed Worker is serving HTML
instead of JavaScript. This cannot be corrected by pasting JS into another file.
Check Cloudflare Worker static assets configuration and last successful deployment.

VALIDATION
node --check public/app.js
